# 図中で使用している公式素材

構成図のロゴ／アイコンは、各サービスの公式サイトまたは公式配布元から取得しています。

- Render: [Render Brand Kit](https://render.com/)
- Neon: [Neon](https://neon.tech/)
- Ruby on Rails: [Rails公式リポジトリのWebサイト素材](https://github.com/rails/website)
- Docker: [Docker公式サイト](https://www.docker.com/)
- PostgreSQL: [PostgreSQL公式サイト](https://www.postgresql.org/)
- Google: [Google公式認証UI素材](https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg)
- Slack: [Slack Media Kit](https://slack.com/media-kit)
- GitHub: [GitHub公式サイト](https://github.com/)
- Amazon S3: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/)

各素材の商標・利用条件は、各公式配布元のガイドラインに従います。

構成図のSVG本体には、MarkdownプレビューやGitHub上でも表示できるよう、これらの画像をData URIとして埋め込んでいます。
